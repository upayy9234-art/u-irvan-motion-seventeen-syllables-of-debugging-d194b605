This program was written for the make.fun bounty **"Seventeen Syllables of Debugging"** ($5). It prints a single haiku about debugging — exactly 17 syllables in the classic 5-7-5 pattern, three lines, no more and no less. The program holds a few freshly written candidate haikus, scores each one against the brief (correct 5-7-5 counts, on the topic of debugging, fresh, and pleasant to read), then prints the winner.

> Red tests blink at dawn
> one stray print reveals the flaw
> green lights return home

## Run it

```bash
python3 main.py
```

Pure Python standard library — no external packages. The output is fully deterministic: the same haiku, byte for byte, on every run. The program also writes the winning haiku to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
